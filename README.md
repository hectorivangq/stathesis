# STATHESIS Health Analytics

Source of stathesis.com, the bilingual (English and Spanish) site for STATHESIS Health Analytics, San Juan, Puerto Rico.

Static files served by GitHub Pages: pushing to `main` publishes. **This repo is the source.** The pages were first generated by a build workspace outside the repo; that workspace is no longer used (2026-10-27), so edit the HTML, CSS and JS here directly. Nothing gets copied over the repo any more.

- **Pages:** 11 HTML files, English at the root (`/`, `about/`, `services/`, `contact/`, `privacy/`, `404.html`) and Spanish under `es/` (`es/`, `es/sobre/`, `es/servicios/`, `es/contacto/`, `es/privacidad/`).
- **Shared parts are repeated in every page by hand:** the `<head>` (including the Google Analytics tag `G-16YY1DPBME`), the header with its mobile menu, the footer with its Privacy/Privacidad link, and on the six pages that have it (home, about and services, in both languages) the closing band. Change all the files that carry a part, in both languages.
- **Styles and scripts:** `css/tokens.css` (every colour, type, spacing and motion value), `css/base.css` (from the starter kit), `css/site.css` (the site's components), `js/site.js` and `js/motion.js`. Pages link them with a version query (`?v=20261027a`); bump it in every page when a CSS or JS file changes, so browsers don't keep a stale copy.
- **Keep:** `CNAME`, `.nojekyll`, this README.
- **Check a change:** serve the folder (`python3 -m http.server`), look at it at 320, 390, 768 and 1440 px wide, and paste `js/qa-audit.js` into the browser console on the pages you touched; it reports overflow, image, heading, spacing, tap-target and hidden-content problems.

What sets this site apart from the studio's other builds (2026-10-27), so later edits keep it: the 3×3 dot-grid menu button and roman-numbered phone menu, 6px button corners, the closing band split into heading and ask behind a hairline (no seal), and a footer without a giant wordmark.
