# STATHESIS Health Analytics

Source of stathesis.com, the bilingual (English and Spanish) site for STATHESIS Health Analytics, San Juan, Puerto Rico.

Static files served by GitHub Pages. The pages are generated, so don't edit them here: change `build/content.py` in the workspace, run `build/build.py`, and copy `site/` over this repo (keep `CNAME`, `.nojekyll` and this README).

**Added here directly, not yet in the workspace** (2026-10-21 and 2026-10-22): the Google Analytics tag `G-16YY1DPBME` in every page's `<head>`, the privacy pages `privacy/` and `es/privacidad/`, and the Privacy/Privacidad link in every footer. Put all three into the workspace's templates before the next copy-over, or it will remove them.
